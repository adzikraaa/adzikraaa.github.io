# Portfolio image files

Replace each placeholder by saving your image with the exact filename below. The page loads local files automatically; no code edits are needed. Keep the paths and lowercase extensions as written. WebP or JPG images work best.

## Profile

- `profile.jpeg` — portrait photo for the homepage. A vertical, well-lit head-and-shoulders photo works best.

## RevoU certificate

- Save the certificate in `certificates/` with the base name `revou-software-engineering` and its original `.png`, `.jpg`, `.jpeg`, `.webp`, or `.pdf` extension. The page detects these formats automatically and embeds the PDF when present. Keep the full certificate visible; landscape orientation is preferred.
